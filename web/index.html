物理

    
    
默认关闭 → 机器人保持初始的静止站立姿态。开启后会真实跑 mj_step；由于模型没有控制器，机器人会因重力倒地，可用「复位姿态」恢复。

    

  







  

    
桌面

    
左键拖动 = 旋转 · 滚轮 = 缩放 · 右键拖动 = 平移

    
右侧「运动仿真」= 回放策略跟踪打拳的动作

  

  

    
头显（Quest 等）

    
左摇杆 = 前后左右移动 · 右摇杆 = 30° 转向

    
A / X = 把机器人摆到正前方 · B / Y = 世界复位

    
底部「进入 VR」= 沉浸式；「半透明 VR」= 背景透明，能看到眼镜外的真实环境
