# 膝 149° 极限蹲（收髋 / 不压躯干版）

> 第三版。`squat_stand.py`（膝 107°）和 `squat_deep.py`（膝 122°，碰撞贴死）
> 都不动，这一版按需求把膝角推到 **149°**，同时**不让大腿压到躯干**、
> 手臂也不张开。

```bash
cd sim/vendor/bxi_controller_ros2/src/bxi_example_py_elf3/launch
python squat_extreme.py                    # 膝 149°，自动搜前倾/摆臂
python squat_extreme.py --max-hip 130      # 髋再收一点（躯干会抬高 2 cm）
python squat_extreme.py --return           # 站→蹲→站 完整循环
python squat_replay.py --traj squat_extreme_traj.npz \
       --scene elf3_squat_x.xml --mode phys     # 物理验证（必须换场景）
```

产物：`squat_extreme_traj.npz`（139 帧 / 2.78 s）、`squat_extreme_cycle_traj.npz`
（239 帧 / 4.78 s）、`elf3_squat_x.xml`（带 exclude 的派生场景）、
`logs/squat/squat_extreme_cycle.gif`（侧视）、`squat_extreme_cycle_34.gif`（3/4 视角）、
`squat_extreme_sheet.png`、`squat_torso_gap.png`（收髋前后对比）。

轨迹与场景都在 `../data/mujoco_simulation/`，但脚本支持**只写文件名**：
找不到时会自动去数据目录 / 脚本目录 / 当前目录兜底（`resolve()`）。
所以 `--traj squat_extreme_cycle_traj.npz` 在 `launch/` 下直接可用。

### 四份轨迹 npz 的区别

| 文件 | 动作 | 帧数 / 时长 | 起 → 止躯干高 |
|---|---|---|---|
| `squat_extreme_traj.npz` | **站 → 蹲**（预蹲 + 下蹲 + 0.7 s 保持），停在蹲姿 | 139 / 2.78 s | 1.034 → 0.523 m |
| `squat_extreme_cycle_traj.npz` | **站 → 蹲 → 站**，回到站姿，可无缝循环 | 239 / 4.78 s | 1.034 → 1.034 m |
| `squat_extreme_down_traj.npz` | 循环的前段：**只下蹲**（预蹲 0.5 s + 下蹲 1.55 s + 保持 0.4 s） | 124 / 2.48 s | 1.034 → 0.523 m |
| `squat_extreme_up_traj.npz` | 循环的后段：**只起立**（蹲 → 站） | 102 / 2.04 s | 0.523 → 1.034 m |

两份单程轨迹由循环版切出来，帧数据**逐位取自循环轨迹**（不重新解 IK）：

```bash
python split_traj.py squat_extreme_cycle_traj.npz            # 默认不带保持帧
python split_traj.py squat_extreme_cycle_traj.npz --hold 0.4 # 下蹲末尾留 0.4 s 蹲姿（当前入库版）
```

- 接缝对得上：`down` 末帧 == `up` 首帧（同一个蹲姿），两段可以直接首尾相接；
- `--hold` 的用处不只是"多坐一会儿"：没有保持帧时，`squat_replay.py --mode phys`
  只能拿最后 0.3 s 当检查窗，而那时 PD 还差 10° 没跟上，会被误判成"不稳定"
  （实测波动 29.4 mm）；补 0.4 s 后波动降到 1.0 mm，判定为站稳；
- 顺带修了回放的检查窗：原来只有下界、一直敞口到轨迹末尾，对**循环轨迹**会把
  2.75 s 之后的起身也算进去（波动被算成 522 mm）。现在窗口封在保持段内
  `[t_pre+t_desc+0.15, t_pre+t_desc+t_hold]`，四份轨迹的保持波动统一是 0.8~1.0 mm；
- 相位时长从 `meta` 的 `t_pre / t_desc / t_hold` 读，不写死，所以
  `squat_stand` / `squat_deep` 的循环轨迹同样能切。

单程版的 `meta` 里额外带 `segment`（`down` / `up`）、`start_z` / `end_z`、`source`，
`squat_replay.py` 据此选检查窗（`down` 取保持段、`up` 取最前 0.3 s 的蹲姿）。

导出给外部使用（`logs/squat/npz/`）：上述四份 npz 都在，字段
`time / qpos(38) / dt / joint_names / meta`。

单程动作的小动画：`logs/squat/squat_down.gif`、`logs/squat/squat_up.gif`。

3/4 视角动画的机位（方位 230°、俯角 −6°、距离 2.35 m，正好能同时装下站姿的头顶和
蹲姿的脚）：

```bash
python squat_replay.py --traj squat_extreme_cycle_traj.npz \
       --scene elf3_squat_x.xml --gif squat_extreme_cycle_34.gif \
       --every 3 --width 960 --height 540 --az 230 --el -6 --lookat 0 0 0.60 --dist 2.35
```

## 1. 结果

| | 标准版 | 极限折叠 | **膝 149°（本版）** |
|---|---|---|---|
| 膝角 | 107° | 122°（碰撞贴死） | **149°（限位 150°）** |
| 躯干高度 | 0.784 m | 0.694 m | **0.523 m** |
| 相对站姿 | −24.2% | −32.9% | **−49.4%** |
| 髋 / 踝 | −79.5° / −40.4° | −100.1° / −39.2° | **−138.2° / −29.3°** |
| 髋高 | 0.44 m | 0.35 m | **0.161 m** |
| 躯干-大腿间隙 | — | 贴合 | **7.7 cm**（此前 1.7 cm） |
| 稳定裕度（蹲姿） | 9.1 cm | 11.0 cm | **9.7 cm** |
| 物理保持波动 | 1.0 mm | 0.7 mm | **0.8 mm** |
| 脚踝滑移 | 1.4 mm | 3.9 mm | 7.2 mm |

躯干比标准版低 **26.1 cm**。比"膝 149° 压到底"那一版高 **4.8 cm**——那 4.8 cm 正是
换来的 7.7 cm 躯干-大腿间隙（见第 4 节）。

## 2. 为了 149° 放开的两样东西

**（a）大腿/小腿碰撞。** 两个碰撞胶囊半径各 5 cm，121.8° 就贴合；149° 时穿插约 4 cm。
派生场景 `elf3_squat_x.xml` 里加了

```xml
<contact>
  <exclude body1="l_hip_z_link" body2="l_knee_y_link"/>
  <exclude body1="r_hip_z_link" body2="r_knee_y_link"/>
</contact>
```

视觉网格仍会互相穿过——这是"忽略碰撞半径"的直接后果。

**（b）IK 的 q1 搜索范围。** 原来 `squat_stand.leg_ik` 限制在 −100°（正常蹲姿够用），
149° 时大腿要折到 −130° 以下，必须放宽。新脚本里另写了一份 `leg_ik_wide`
（搜索下限 −160°），不改原文件。

## 3. 髋角是被"脚掌平贴"逼出来的

膝角锁死后髋-踝的端点距离只剩 `2×0.32×cos(74.5°) = 0.171 m`。
脚掌要平贴就得 `ankle = −(θ+hip+knee)`，前倾 θ 增大时 hip 越来越负、两者相互抵消：

```
θ =  0°   髋  −74.5°   踝 −74.5°（超限 24.5°）  torso 0.594  ✗
θ = 12°   髋 −114.2°   踝 −46.8°（达标）        torso 0.566  ✓
θ = 18.5° 髋 −138.2°   踝 −29.3°               torso 0.523  ✓  ← 现在
θ = 22°   髋 −153.4°   踝 −17.6°               torso 0.488  ✓
θ = 23°   髋 −158.4°   踝 −13.6°               torso 0.475  ✓  ← 上一版
θ ≥ 24°   折不到 149°（腿长不够，脚踝够不到原位）
```

**蹲得越低，髋角就越极端**，这两件事在几何上是同一件事：端点只剩 0.171 m，
髋必须"坐"到踝的正上方，大腿就竖起来贴到肚子上。

腰部三关节（`waist_y/x/z`）全程为 0——躯干前倾全部由基座俯仰完成，
不借用腰（原因见 `squat_stand.md`：waist_y 转的是骨盆，转它只会把腿整体往前甩）。

## 4. 躯干-大腿碰撞：把髋角收到 138°

上一版髋 −158.4° 时，大腿上端直接压进躯干下缘：

- 碰撞体（`torso_2_collision` ↔ `l_hip_z_1_collision`）最小距离只有 **1.71 cm**
- 视觉网格（mesh）已经互相插进去
- `self_contacts` 一直是 0 —— 它只报"已经接触"，抓不到这种贴脸状态

`search()` 现在多了两条硬约束：`--max-hip`（默认 140°）和 `--min-torso-gap`
（默认 0.06 m），两者都是用 `mj_geomDistance` 逐姿态实测的。

髋角上限与代价：

| `--max-hip` | 前倾 | 躯干高度 | 髋角 | 相对站姿 |
|---|---|---|---|---|
| 120° | +13.5° | 0.558 m | −119.5° | −46.0% |
| 125° | +15.0° | 0.549 m | −124.9° | −46.9% |
| 130° | +16.0° | 0.542 m | −128.6° | −47.5% |
| 135° | +17.5° | 0.531 m | −134.3° | −48.6% |
| **140°（默认）** | **+18.5°** | **0.523 m** | **−138.2°** | **−49.4%** |
| 145° | +20.0° | 0.510 m | −144.4° | −50.7% |

每多蹲 1 cm，髋角就要多折 4~5°。默认取 140°：躯干-大腿间隙 7.7 cm（视觉网格 4.0 cm），
再往下压就会重新贴上去。

### 外撇膝盖能不能两全？不能

试过用 `hip_z` 把膝盖外撇（数值 IK 支持，脚掌仍保持水平）：

```
外撇  0°  髋 −148.8°  躯干 0.499  躯干-大腿 4.6 cm
外撇 12°  髋 −150.0°  躯干 0.494  躯干-大腿 4.2 cm
外撇 23°  髋 −154.0°  躯干 0.477  躯干-大腿 3.0 cm
外撇 35°  髋 −165.0°  躯干 0.440  躯干-大腿 0.0 cm   ← 撞上
```

外撇让大腿根更靠躯干侧下方，间隙**反而更小**，同时踝关节横滚（限位 ±20°）
也不够用。所以本版不外撇。

## 5. 手臂：外展从 26° 收到 13°

髋角收小后大腿不再顶到肘部高度，手臂可以贴身了：

| | 上一版 | 现在 |
|---|---|---|
| 大臂前摆 | −69° | **−66°** |
| 大臂外展 | 26°（0.45） | **13°（0.22）** |
| 前臂折回 | 95° | 95°（限位 1.658 已到顶） |
| 手腕位置 (x, y) | (0.35, 0.40) | **(0.40, 0.29)** |
| 肘-膝 / 肘-大腿（全程最小） | 18.3 / 9.0 cm | **18.6 / 8.6 cm** |
| 蹲姿裕度 | 9.9 cm | 9.7 cm |

外展再收到 8°（0.14）会有两个问题：`search_arm` 在"肘-大腿 ≥ 9 cm"的约束下找不到
向前摆的解，只能把手臂留在身后（裕度掉到 5.5 cm）。**13° 是这版能收到的极限。**

前臂仍然折到 95°（`elbow_y` 限位 1.658 已到顶），手腕垂在膝前 0.40 m 处，
不再水平前伸。

## 6. 静态稳定性

- COM 投影 `(+0.044, 0.000)` m，脚心略前
- 稳定裕度 **9.7 cm**（脚长的 44%），远超 2 cm 阈值
- 全程最小 8.9 cm（下蹲中段 t≈1.38 s）
- 关节力矩最大占用 16.7%（肩 8.3 N·m / 50），腰 12.0%
- PD×8 @ 1 kHz 物理回放：躯干落到 0.511 m（PD 稳态误差 1.2 cm），
  保持段波动 **0.8 mm**、保持段裕度 6.9 cm、脚踝滑移 7.2 mm，判定站稳

## 7. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--knee` | 149 | 目标膝角，上限 150°（关节限位） |
| `--min-margin` | 0.035 | 稳定裕度下限，自动搜前倾时用它筛 |
| `--max-hip` | 140 | 髋屈曲上限（deg），直接决定躯干能压多低 |
| `--min-torso-gap` | 0.06 | 躯干-大腿碰撞体最小间隙（m） |
| `--arm` | 自动 | 大臂前摆（负=向前），默认搜到 −66° |
| `--elbow` | 1.65 | 前臂折回角（限位 1.658） |
| `--arm-out` | 0.22 | 大臂外展（13°）；0.45 是上一版，张得开 |
| `--reach-max` | 0.40 | 手腕前伸上限，越小手臂越贴身 |
| `--min-elbow-gap` | 0.09 | 肘-膝/肘-大腿碰撞体最小间隙 |
| `--no-optimize-arm` | — | 关掉摆臂角自动搜索 |
| `--return` | off | 加回程 |

---

## 8. 注意事项

- **必须用 `elf3_squat_x.xml` 跑物理**。用原来的 `elf3_squat.xml` 时大腿和小腿的
  碰撞会把腿顶开，蹲不到 149°。
- **`self_contacts` 不是碰撞判据**：它只在已经接触时报，贴到 1.7 cm 也不吭声。
  判断穿插要用 `mj_geomDistance`（`search()` 已内置）。
- 视觉上大腿和小腿仍是穿插的（碰撞被 exclude），这不是渲染错误。
- 想再蹲低，只能放开 `--max-hip`；想更安全，就把 `--max-hip` 降到 130（躯干 0.542 m）。
