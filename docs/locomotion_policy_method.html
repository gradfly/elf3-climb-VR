3参考步态层：脚本控制器 → 参数化参考表

这是整条链路的"先验"，也是策略能力的天花板。

3.1 四相位准静态步态（crab_climb.py）

每个"步"分四相位：

  1. LOAD——重心平移到支撑脚正上方；
  2. SWING——摆动脚抬到 max(z0,z1)+5.5cm，横移过踏面边界；
  3. LAND——落到目标踏面；
  4. SETTLE——重心回到双脚中点，骨盆侧倾回目标值。

每步 0.9 s @ 50 Hz = 45 帧；一个周期（先左后右两步）90 帧 = 1.8 s。

  • GATHER / SPLIT 站姿序列：每个落脚面给 L/R 各一个固定落点（中心 ∓ off）， 相邻转换只动一只脚，始终保留清晰的支撑多边形；
  • 骨盆侧倾解级高：25 cm 级高只需 waist_x 侧倾 10.4°（限位 15°）， 绕开"平脚 + 踝限位 ±20°"的瓶颈；
  • DLS 数值 IK：闭式解只作种子，每帧收敛到 < 1 mm，全程检查关节限位与 质心-支撑面裕度；重心时序在归一化进度 p ∈ (0.32, 0.78) 区间钉在支撑脚正上方；
  • 回退梯度 LADDER：IK 不收敛时按（重心转移比例 lam，摆动脚姿态权重）逐级放松。

4地形感知与参考选择（ref_table.py）

4.1 高度扫描

terrain_scan 从躯干向下打射线，yaw 对齐网格 21(y) × 13(x)、 分辨率 0.1 m、覆盖前后 ±0.6 / 左右 ±1.0 m（螃蟹步加宽侧向）， include_geom_groups=(0,) 只打地形。 scan_to_heights() 把射线距离换算成"躯干高出地形"的高度场 [B, 273]。

4.2 (rise, tread) 估计

  1. 取中央 3 列 x 的中值得 y 向剖面（抗机器人自腿遮挡的单格凹陷）；
  2. 3 点中值滤波 → 上升边缘 dh = h[iy] − h[iy+1]（地形升高 ⇒ height 变小）；
  3. 检测带 |y| ∈ (0.15, 1.00)，边缘须满足 0.03 < dh < 0.30（参考表最大档才 0.22，更大的"台阶"必是遮挡/异常）；
  4. rise = 各边缘 dh 的高斯加权均值（σ = 0.5 m，离机器人越近权重越大）， 两侧都认（允许倒着接近）；tread 只看 +Y 半侧，取相邻边缘间距均值；
  5. EMA 平滑：rise α = 0.5、tread α = 0.3；长期测不到边时 rise 以 0.9/步回落； 测不到边（平地）时 tread 取 per-env 兜底值——按 terrain_origins 最近邻反查该 env 所在地形列的真实踏面（0.40 / 0.40 / 0.30 / 0.24）。 每 5 步刷新一次。
为什么兜底要按列给：四列真实踏面各不相同，一个全局标量最多只能对齐一列。 拿 terrain_types 当列号也不行——本版 mjlab 实测对不上（type=0 同时出现 12.5 和 8.0 cm）。

4.3 查表插值

对 (rise, tread, phase) 做双线性 + 相位线性插值，返回 q_ref[29] 和该档参考步速 v_ref。纯 numpy/torch、不 import mjlab，训练与回放（crab_replay）共用。

5残差动作项（residual_action.py）

整个方法的"接缝"就在这一行公式上。

q_cmd = q_ref(rise, tread, phase) + scale · clip(Δq, ±clip_rad)
        └── 时变 offset，每步由参考表给出      └── 策略输出，即"残差"

继承 mjlab JointPositionAction，只重写 process_actions / reset。要点：

  1. 相位是 per-env 状态量：phase += (v_cmd / v_ref) / 90， 速率夹在 [0.6, 1.8]。指令快则步频快，几何上限是 可达速度 = tread × 1.8 / 1.8 = tread。 开局 hold 25 步（0.5 s）相位冻结；相位平移 33/90 使 phase=0 落在 双支撑帧，初始相位随机取 {0, 0.5}。
  2. α 课程（参考幅度）：q_ref = q_stand + α·(q_gait − q_stand)， α 从 0 线性升到 1，默认 1500 iteration × 24 步。α=0 时参考退化为默认站姿，与已验证的 基线任务（动作全零 = 站姿）同难度。续训必须用 ELF3_ALPHA=1.0 钉住， 或用 ELF3_ALPHA_START 接上。
  3. 限幅按关节组：腿 ±0.55 rad、腰 ±0.20、臂 ±0.20（可用 ELF3_LEG_CLIP 等覆盖）。0.40 时代 76% 输出顶死限幅、梯度在 clamp 外恒 0； 放宽到 0.55 解除天花板。限幅同时是动作映射，可用旧 checkpoint 做零样本对拍。
  4. 诊断开关：ELF3_RESIDUAL_SCALE=0 纯参考开环走，用来拆分 "参考自带偏置"与"残差学出偏置"；ELF3_RESET_RAMP=25 每回合开局做站姿→参考软启动。
一致性原则：内部量（ref_joint_pos / phase / rise_est / scan_ok ...）全部暴露为 只读属性，offset、观测 joint_pos_ref_err、奖励 ref_tracking 三者 读同一份 _ref_q——否则前 N 步会白扣奖励。

7奖励函数（残差版重排后）

主线：速度项只管"别停、别超速"；步态质量全权交给 ref_tracking + 抬脚正激励； 方向约束单列。所有数值都经实跑标定，代码注释保留了每次改动的实测依据。

项权重作用与关键设计
forward_progress_y+5.0 替换内置瞬时速度 exp 核。参考步态 COM 是脉冲式（峰值 1.6 m/s、26% 帧倒退）， 瞬时核只会奖励"匀速蹭走"。改为 EMA（tau=1.8 s = 一个步态周期）平均推进 ÷ 指令， 夹 [0,1]：跟参考 0.85 / 蹭走 0.70 / 站住 0。原地踏步 env 打五折，避免抬高 value baseline。
ref_tracking+2.0 12 腿关节跟踪 exp 核（σ = 0.30 rad）——唯一逼出"真正侧步"的项。用 exp 而非 L2， 避免退化成行为克隆。
swing_clearance+2.0 脚底离地高度 / target，平方后按脚平均。破"抬脚无收益、失衡 −5 分"的 不对称稳态（贴地蹭）。平方是关键：线性版被"贴地快蹭"刷分（air_time 涨、peak_height 反降）。 带 max_height 截断 + 竖直姿态门控（up_z > 0.6）防摔倒扑腾刷分。
air_time+1.0 门槛 threshold_min 0.05 s（原 0.12 让这条恒为 0）。
upright+0.5 从 1.0 压到 0.5：原值 0.92/步属"白送分"，策略优先生存不前进。
foot_swing_height / foot_clearance−1.0 / −2.0 target 统一压到 0.15 m（原 0.18 与 α<1 时参考只抬 5~12 cm 直接打架）。
yaw_drift−4.0 帧间偏航角速度平方，死区 0.08 rad/s。原 sin²(yaw) 版本 绕圈"无罪"（20 s 转 367° 只罚 0.018）；纯平方版在 0.09 rad/s 处梯度塌缩。权重按 w ≈ 1853 / ep_len 重标。
lateral_bias−20 机身系纵向速度 EMA(1.8 s) 偏置平方，死区 0.03——治步态自带的 X 向漂移 （三档实测都是 +0.10~0.13 m/s）。⚠️ −80 会把策略压垮成"别动"（ref_tracking 0.98→0.30）。
lateral_drift−0.2 (x − x₀)² 位移惩罚（保留，量级已由 lateral_bias 覆盖）。
action_rate_l2−0.006 从 −0.1 一路压下来：原值 −2.89/回合是前进奖励的 2.2 倍，等于奖励"别动"。
foot_slip−0.2打滑惩罚（基线保留）。
dof_pos_limits−1.0关节限位（基线保留）。
is_terminated−250 摔倒一次性惩罚。−5 形同虚设（×dt 只有 0.1 分）；−400 把策略逼成"站着不动" （摔率 78% 时走路的期望收益转负）→ −250 是平衡点。
ref_probe1e-9 探针：把 rise_est / tread_est / scan_ok / ref_alpha 写进 Metrics。 权重为 0 时 mjlab 连 func 都不调用，故用 1e-9。
A/B 开关：ELF3_REWARD_OFF=项名,项名 一次关一批做归因。 实测曾出现"训练指标一路向好、eval 反而退步"的静默换目标，靠它把责任定位到单项。

8课程与训练算法

8.1 三重课程

  1. 地形课程（自研 terrain_levels_time，替换内置 terrain_levels_vel）：内置判据"走够 |cmd| × 剩余时间"导致摔得越早 要求越高，全部 env 钉死 level 0（曾因此 12000 轮无效）。新判据： 升级 = 活到 25%（5 s）且离出生点 ≥ 0.90 m；降级 = 活不到 40%（8 s）。 碗底半宽 flat 1.00 / easy 0.80 / mid 0.40 / hard 0.62 m，0.90 等于"至少踏上第一级"。
  2. 指令速度课程：lin_vel_y 三段 (0.10,0.14) → (0.13,0.17) → (0.14,0.20)。上界与"步态几何可达速度 = tread"对齐， 避免物理上追不上的指令把梯度削平。
  3. 参考幅度 α 课程：见 §5。
初始地形等级钉 0、四档 step_height_range 低端全部对齐 0——保证存在 "先在平地站稳"的阶段（曾实测 level 0 的八个 env 里 7 个出生就在 6~14 cm 台阶上）。

9安全终止、域随机化与地形

终止条件

  • 躯干 / 腰 / 头触地力 > 20 N 即终止——fell_over(70°) 挡不住 "跪在台阶上蹭上去"这类局部最优；
  • 倾角 > 70°、超时、出地形边界。

域随机化

  • 推撞：每 3~6 s，±0.2 m/s / ±0.15 rad/s（从每 1~3 s ±0.3 降下来：爬台阶 容错小一个量级）。可 ELF3_PUSH_SCALE 缩放——训练分布比测试暴力一个数量级时， 策略会变成"抗推专家"而不是"走得好"。
  • 脚底摩擦 0.4~1.2、编码器偏置 ±0.015 rad、躯干质心偏移 ±2.5~3 cm、出生位姿 ±0.2 m / yaw ±0.15 rad。

地形

pyramid_stairs_inv 倒置金字塔：碗底出生，向外走全是上台阶。 正金字塔的 origin 在最高平台，曾因此白训 12000 轮。

续训后当场崩α ramp 从 0 重来，参考打回站姿ELF3_ALPHA=1.0 / ELF3_ALPHA_START
play 漂移数字不可信play 配置的指令范围被放宽评测必须 --freeze-command
