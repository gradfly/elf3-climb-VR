# 极限折叠蹲（大腿贴小腿）

> `squat_stand.py` 的「更深」版本，原版一行没动。
> 目标：把腿折到**大腿与小腿刚好接触**、躯干压到最低，再看这个姿态还站不站得住。

```bash
cd sim/vendor/bxi_controller_ros2/src/bxi_example_py_elf3/launch
python squat_deep.py                       # 自动搜最低姿态 + 生成轨迹
python squat_deep.py --check-only          # 只算不打印文件
python squat_deep.py --return              # 站→蹲→站 完整循环
python squat_replay.py --traj squat_deep_traj.npz --gif out.gif
python squat_replay.py --traj squat_deep_traj.npz --mode phys     # 物理验证
```

产物：`data/mujoco_simulation/squat_deep_traj.npz`（126 帧 / 2.52 s）、
`squat_deep_cycle_traj.npz`（216 帧 / 4.32 s，`--return`）、
`logs/squat/squat_deep_cycle.gif`、`squat_deep_sheet.png`、`squat_compare.png`。

---

## 1. 结果

| | 标准版 `squat_stand` | 极限版 `squat_deep` |
|---|---|---|
| 躯干高度 | 0.7839 m（−24.2%） | **0.6941 m（−32.9%）** |
| 髋 / 膝 / 踝 | −79.5° / +106.9° / −40.4° | **−100.1° / +121.8° / −39.2°** |
| 大腿-小腿间隙 | ~20 mm | **2.0 mm（贴合）** |
| 稳定裕度 | 9.1 cm | **11.0 cm** |
| 关节力矩占用 | 14.2% | 14.4% |
| 物理保持段波动 | 1.0 mm | **0.7 mm** |
| 手撑地 | 不需要 | **不需要，而且够不到** |

躯干再低 9 cm，膝盖折到物理极限，静态裕度反而更大（因为极限版手臂前伸把
COM 拉到了脚心正上方）。

---

## 2. 深度是被三条边界卡住的

1. **膝（几何硬限）**：大腿 `l_hip_z_1_collision` 与小腿 `l_knee_y_collision`
   碰撞胶囊半径各 5 cm，膝角到 **≈121.8°** 时两者贴合（间隙 2 mm），再折就穿插。
   脚本用 `mj_geomDistance` 二分出这个角，不是拍脑袋定的 150° 限位。
2. **踝（关节限位）**：脚掌要平贴就得 `ankle = −(θ+hip+knee)`，限位 −50°。
3. **腿长**：脚踝必须留在世界原位（脚不能滑），髋到踝的距离被膝角锁死。

## 3. 关键：前倾角 θ 是解药，不是毒药

直觉上「蹲得越低越要往前倾」，但更反直觉的是：**前倾还能把踝关节从超限里救回来**。

θ 增大时臀部后移 `0.3825·sinθ`、脚踝相对髋前移，小腿相对竖直的夹角反而变小，
`ankle` 需求从 −61°（θ=0）一路回升到 −39°（θ=17.5°）：

```
θ = 0°   膝 121.8°  →  ankle −61.0°   超限 11°   ✗
θ = 10°  膝 122.2°  →  ankle −48.7°   刚好达标    ✓  躯干 0.719
θ = 15°  膝 121.9°  →  ankle −42.4°   余 7.6°     ✓  躯干 0.705
θ = 17.5° 膝 121.8° →  ankle −39.2°   余 10.8°    ✓  躯干 0.694  ← 自动搜到的最优
θ ≥ 20°  膝折不到 122°（腿长不够，脚踝够不到原位）
```

所以脚本是「给定膝角 = 接触极限，扫前倾角，取躯干最低且裕度 ≥ 4 cm 的那个」。
`--lean` 可以手动钉死某个角度。

---

## 4. 为什么不用手臂撑地

用户提的备选方案（撑地）在这个姿态下**两条都不成立**：

**（a）不需要。** 静态裕度 11.0 cm（脚长的 50%），比标准版还宽。物理仿真 1 kHz × 8 倍
刚度跑完全程，保持段躯干波动 0.7 mm、脚踝滑移 3.9 mm，不需要额外支撑点。

**（b）也够不到。** 极限蹲时肩高 0.777 m，手臂从肩到腕的最大下垂量 0.480 m
（上臂 0.256 + 前臂 0.256，肘关节限位 −55°，不能完全伸直），手最低只能到
**0.297 m**，离地面差 30 cm。这个数字脚本每次都会打印：

```
[手臂撑地] 肩 z=0.777 m，最大下垂 0.480 m → 手最低 0.297 m
           够不到地面（差 30 cm）
```

这是硬件比例决定的：腿长 0.64 m、臂展 0.51 m，蹲到底时手必然悬空。
真要用手撑地只能改成「四肢着地」的跪撑/爬行姿态，那是另一套动作
（见 `prone_crawl.py`）。

## 5. 参数

```bash
python squat_deep.py --knee-gap 2 --min-margin 0.04 --lean 17.5
                     --arm -0.5 --elbow 0.8 --return
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--knee-gap` | 2.0 | 大腿-小腿目标间隙 mm，越小折得越死 |
| `--min-margin` | 0.04 | 静态裕度下限，自动搜索时用它筛掉不稳的姿态 |
| `--lean` | 自动 | 手动指定前倾角；不给就扫 0~26° 取最优 |
| `--arm` / `--elbow` | −0.50 / 0.80 | 蹲下时手臂前伸，顺便把 COM 调回脚心 |

## 6. 已知限制

- 膝角上限由**碰撞胶囊**决定（121.8°），不是关节限位（150°）。想让腿折得更狠，
  得先改 XML 里大腿/小腿的碰撞体尺寸。
- 前倾 20° 以上腿长不够：脚踝留在原位这个约束把 θ 卡死了。若允许脚在地上滑动，
  还能再深一点，但那就破坏了「脚不动」的前提。
- 物理回放的 PD 有 ~7° 稳态误差，蹲姿实际比目标再低 1.2 cm（0.6817 vs 0.6941），
  裕度相应从 11.0 降到 8.1 cm，仍然安全。
