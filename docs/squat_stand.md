# 站立 → 蹲姿动作序列（squat stand）

> 目标：产出一套**可验证的开环起蹲动作**——关节轨迹 npz + 回放/渲染脚本，
> 并证明蹲姿满足**静态稳定平衡条件**（ZMP 在支撑多边形内、关节力矩不超限、
> 物理仿真下能站住）。

---


## 2. 姿态定义

### 2.1 站姿：先把脚掌放平

训练 nominal pose 是 `hip_y=-0.3, knee_y=0.6, ankle_y=0`。这三者相加是 **+0.3 rad**，
意味着脚掌前倾 17°——实际是**踮着脚尖站着**，脚底最低点在脚尖、脚跟离地。

把踝关节补成 `-(hip+knee) = -0.3` 之后脚掌才真正水平，此时基座高 **1.0339 m**，
与训练初始高度一字不差，反过来印证这才是这组关节角的几何自洽解。

### 2.2 蹲姿：矢状面折叠 + IK 保证脚不滑

腿部两连杆（大腿 0.32 + 小腿 0.32）在矢状面内解 IK：给定脚踝的世界目标
`(x=0, z=0.04)` 和基座下降量，反解 `(hip, knee, ankle)`，约束是

```
脚踝落在世界原位     → 脚不前后滑（实测全程 < 1e-15 m）
脚掌世界俯仰 = 0     → ankle = −(θ + hip + knee)
```

只用 `knee = −2·hip` 的对称解也能站，但它只适用于基座不倾斜的情况；带前倾后
必须走完整 IK。

### 2.3 躯干前倾必须用**基座俯仰**，不能用 waist_y

这台机器的腰部三个关节挂在 `torso_link` **下方**，腿挂在腰下面（肩直接挂 torso）。
所以 `waist_y` 转的是「骨盆相对躯干」——转它等于**把腿整体往前甩**，躯干纹丝不动。
实测 `waist_y=-0.14` 时躯干角度没变、脚却前移了 8.8 cm，支撑多边形整体跟着偏。

正确写法：基座绕 +y 前倾 θ（四元数 `(cos θ/2, 0, sin θ/2, 0)`），腿在倾斜后的
坐标系里重新 IK。附带好处是臀部自然后移 `0.3825·sinθ`，把重心往脚心拉。

## 3. 动作序列

| 时间 | 阶段 | 说明 |
|---|---|---|
| 0.00 – 0.45 s | 站姿 → 预蹲 | 先下沉 25%（anticipation），手臂起摆 |
| 0.45 – 1.60 s | 预蹲 → 蹲姿 | 主下蹲，smootherstep（首尾速度/加速度都为 0） |
| 1.60 – 2.20 s | 蹲姿保持 | 静止 0.6 s，供静态稳定判据采样 |
| （`--return`）2.20 – 3.45 s | 蹲姿 → 站起 | 回程 |
| （`--return`）3.45 – 3.80 s | 站姿静止 | |

关键点之间插值的是**任务参数**（蹲深 / 前倾 / 手臂），不是关节角——每帧重跑一次
腿 IK，脚踝位置与脚掌水平才逐帧严格成立。插关节角会让脚在地上蹭几厘米。

**蹲姿数值**（默认参数）：

```
躯干 1.0339 → 0.7839 m      下降 0.250 m（24.2%）
前倾 13°    髋 −79.5°  膝 +106.9°  踝 −40.4°   （踝限位 −50°，余 9.6°）
肩前摆 −43°  屈肘 +45.8°  抬头 +10°（补偿前倾，视线保持水平）
```

## 4. 静态稳定判据

### 4.1 判据与结果

| 判据 | 要求 | 实测 |
|---|---|---|
| ZMP/COM 投影在支撑多边形内 | 裕度 > 2 cm | **+9.09 cm**（脚长的 41%） |
| 关节力矩不超电机限值 | < 100% | **最大 14.2%**（waist_y 14.2 / 100 N·m） |
| 自碰撞 | 无 | 无 |
| 摩擦力 | 静态水平力为 0 | 不涉及（无水平外力） |

支撑多边形 = 14 个脚底胶囊球心的 xy 凸包：
`x∈[−0.080, +0.140]`、`y∈[−0.166, +0.166]`，面积 0.072 m²。
蹲姿 COM 投影 `(+0.049, 0.000)`——在脚心（x=+0.03）略前，离脚尖还有 9.1 cm。

全程（含过渡段）最小裕度就是蹲姿稳态的 9.09 cm，说明下蹲过程中重心没有越界。

### 4.2 为什么这个判据成立

静态时 ZMP 就是 COM 的地面投影。双足站立时两脚是两块分离的接触面，但竖直合力
可以按任意非负权重分配到两块面上（合力作用线经过加权平均点），所以只要投影落在
**凸包**内就存在一组合法的地面反力，这就是凸包判据的来源。

### 4.3 物理验证

`python squat_replay.py --mode phys` 用 PD + 重力前馈跑 1 kHz 真物理：

```
躯干高     起 1.0339 → 末 0.7721 m     保持段波动 1.0 mm
关节跟踪   平均 7.36°   最大 13.09°
稳定裕度   最小 4.13 cm   保持段 4.39 cm
脚踝滑移   1.37 mm
[判定] 站稳了：蹲姿静态平衡成立
```

物理下的裕度（4.1 cm）比运动学（9.1 cm）小，是因为 PD 有稳态误差、躯干比目标低
1.2 cm 且略微前倾；仍然远高于 2 cm 阈值。

**增益必须放大 8 倍**：mjlab 的 `kp` 是按 `armature·(2π·10)²` 算的**柔顺**增益，
踝关节只有 33.5 N·m/rad。深蹲时重心在脚心前 5 cm，踝关节要扛 424 N × 0.05 m ≈
21 N·m，33.5 的刚度意味着 0.63 rad 稳态误差——腿会直接塌（实测 kp×1 时躯干从
0.78 m 掉到 0.11 m）。实机位置伺服刚度远高于给 RL 留余量的训练参数，故 ×8。
×8 之后显式积分只能用 1 kHz（500 Hz 发散、×10 也发散），窗口很窄，
`--kp-scale / --sim-hz` 都暴露成参数了，别随手改。

## 5. 参数

```bash
python squat_stand.py --drop 0.25 --lean 13 --arm -0.75 --elbow 0.8
                      --dt 0.02 --return
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--drop` | 0.25 | 基座下降量 m。上限受腿长约束：`lean=13°` 时最大约 0.36（再大报「腿长不可达」） |
| `--lean` | 13 | 基座前倾 deg。前倾越大，脚掌保持水平所需的背屈越小，反而能蹲更深 |
| `--ank-x` | 0.0 | 蹲姿脚踝世界 x，一般保持 0（脚不离原位） |
| `--arm` / `--elbow` | −0.75 / 0.80 | 手臂前摆 / 屈肘，蹲下时前伸配平 |
| `--return` | off | 加回程，生成完整循环 |

`--drop` 调太大时报 `腿长不可达`，提示调小 drop 或调大 lean。

## 6. 已知限制

- 蹲深受**腿长**和**踝关节限位 ±50°** 双重约束：`lean=13°`、drop=0.36 时踝还剩 3.7° 余量，
  再深就报「腿长不可达」；`lean=0`（不前倾）时则先撞踝限位，最多约 0.23 m。
  想蹲更深只能抬脚跟（本序列坚持脚掌全贴地，没有做提踵）。
- 开环序列本身不含平衡控制，PD 跟踪有 7° 量级的稳态误差；这是开环回放的固有性质，
  不是姿态不可行。
- 场景是纯平地面；坡面/台阶上的静态稳定需要另算（支撑多边形会变）。
